# AImd Data Layout

The AImd data directory is split into two top-level areas:

- `data_input`: user-provided starting files and workflow control tables.
- `data_output`: files generated by AImd modules.

Recommended input areas:

- `data_input/protein`: starting protein structures.
- `data_input/ligand`: starting ligand tables, structures, and ligand manifests.
- `data_input/cofactor`: optional cofactor templates.
- `data_input/workflow`: manual pair lists, family maps, and workflow control tables.

Recommended output areas:

- `data_output/cluster`: RGPC graph and cluster outputs.
- `data_output/protein_batches`: protein batches generated by RGPC.
- `data_output/ligand_transformation`: MolLink ligand source and transformation network outputs.
- `data_output/pocket`: TApocketBridge outputs.
- `data_output/docking_out`: DockingHub docking outputs.
- `data_output/scoring`: ClusterScore outputs.
- `data_output/refinement` and `data_output/refined`: refinement outputs.
- `data_output/metaboclip`: MetaboClip bridge and unified backend outputs.

Use `python scripts/migrate_data_layout.py --root .` to create the local
directory tree and copy legacy local input folders into the canonical layout.

Do not commit large input files, docking outputs, model files, or generated
workflow results.

The bundled `data_input/ligand/taxane_molecules.csv` is the small MolLink
example input used for smoke testing and package verification.
